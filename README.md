# Task Manager Simple

Team Name: DevOps Mini Ptoject

This is a simple Task Manager app that shows a notification when a task is marked as complete.  
The project demonstrates Git collaboration using branches and pull requests.

## Reflection


During this project, I learned how Git branches allow team members to work on different parts of a project without affecting the main code. Using pull requests helped review and merge changes safely. I also learned the importance of clear commits and collaboration between frontend and backend development. Overall, this task helped me understand basic DevOps teamwork and version control.
